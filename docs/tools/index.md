# Tools

daymet-mcp exposes eight tools (seven over HTTP, where downloads are not offered). Start with the generated [Tool reference](reference.md) for exact inputs and result fields.

* [Tool reference](reference.md) - Every tool with its inputs, bounds, result fields, upstream endpoints and annotations, generated from the registry.
* [Monthly and annual aggregation](aggregation.md) - Sum versus mean per variable, units, field labels, the 365-day calendar and rounding.
* [Points and grid cells](points-and-cells.md) - How a point maps to a 1 km Daymet cell and how daily and summary values are fetched for it.
* [Areas and downloads](areas-and-downloads.md) - Small-area grids in results, files on disk, backends and the limits that apply.
* [Resources and prompts](resources-and-prompts.md) - The daymet:// guides, JSON references, resource templates and the three task prompts.
